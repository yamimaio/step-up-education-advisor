# Step Up · Test sheet (UAT), Oct 10

The one place where test results live. The worksheet's test section and the Day 4 check-in come from here.

> **Evidence in this repo:** the run transcripts are in `examples/test-runs/<commit>/`. Screenshots, Render logs, the cold tester's runs (a friend's own words) and one transcript with personal details are kept out of the repo; paths under `submission/` refer to that private folder.

**How to run:**
- Use the live URL in a private window, with the real model (Sonnet 5.5).
- Reload the page before each test so it starts a fresh conversation.
- Paste the actual output (or a short quote plus the transcript file name in `examples/`), never just a checkmark.
- Write down the commit each test ran on, in the Commit column: the `production` head for the live site (GitHub, branch `production`), or `git rev-parse --short HEAD` for a local run. The worksheet's "One improvement" needs the commit before and after the fix.
- When a test fails, open one issue for the fix. The PR closes that issue; then rerun the test and add a new row with the result after the fix.
