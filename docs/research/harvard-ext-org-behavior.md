# Harvard Extension Organizational Behavior Graduate Certificate

## Scope and selection

The official Harvard Extension School catalog currently lists seven certificates with **Leadership** or **Management** in the title, plus **Organizational Behavior**, whose official description expressly centers on managing teams and organizational performance. The selected program is **Organizational Behavior Graduate Certificate (Online)** because Harvard describes it as developing insight into “how people work, lead, and collaborate” and covers motivation, group dynamics, leadership, conflict resolution, performance management, change management, and organizational design—the closest match to leading people and organizations rather than managing a function, sector, or strategy.[^1][^2]

The current program facts use the next published intake, **Spring 2027**. Where the school publishes historical certificate-earner data, it is identified separately and is not treated as a Spring 2027 cohort profile.

### Null-field notes

- **credits — null, not published:** the program page states that four courses must be completed “for graduate credit,” but it does not publish a total credit count on that page. A current Spring 2027 Organizational Behavior course is 4 credits, but applying that value to every possible course would be an inference, so the total remains null.[^6][^1]
- **hoursPerWeekMin / hoursPerWeekMax — null, not published:** no program-specific weekly workload estimate appears on the official program page. Harvard’s general FAQ gives a workload relationship—“at least two hours of work outside of class for every hour in class”—but not a weekly estimate for this certificate.[^7]
- **city — null, not published/applicable:** the certificate is fully online and has no required on-site location. Cambridge is the school’s location, not a required program location.[^1][^7]
- **minExperienceYears — null, not published:** no minimum professional-experience requirement appears on the program or enrollment pages. Harvard instead publishes age and education conditions for graduate-credit enrollment.[^8]
- **accreditation — []:** the requested schema specifies an empty array for non-degree programs. Separately, Harvard states that Harvard Extension School is institutionally accredited by the New England Commission of Higher Education; this is not presented as program-specific certificate accreditation.[^7]
- **cohortMedianExperienceYears — null, not published:** no median or average experience figure is published for the Spring 2027 intake. The available 2024 fast-facts document gives bands of employment experience rather than a median or average, and it concerns a different academic year.[^9]

## Uncertain or conflicting items

- **Duration wording conflicts across official pages.** The program-specific page says a student taking two courses per semester can finish in **8 months**, while the general certificate policy page says most four-course certificates can be completed in **one year**. The JSON uses 8 months because the program-specific page is controlling for this program.[^12][^1]
- **Total credits are not published on the program page.** Four required courses are explicitly graduate-credit courses, and a current core course is 4 credits, but the total has not been inferred across every possible elective pathway.[^6][^1]
- **No exact Spring 2027 start day is published on the program page.** It publishes only “Spring 2027”; registration runs November 5, 2026 through January 19, 2027, which is not the program start date.[^1]
- **The GSA lodging rate is seasonal, not one annual number.** FY2027 Boston/Cambridge lodging is $365 in October 2026 and September 2027, $213 from November through February, and $305 from March through August. The JSON scalar uses **$365**, the rate in force on the October 8, 2026 check date; it is not a program cost because the certificate has no on-campus requirement.[^20]
- **Current cohort size, median/average experience, and majority seniority are not published.** A 2024 fast-facts document contains historical employment bands and titles but is not a Spring 2027 class profile, so its experience distribution was not transferred into the JSON cohort field.[^9]
- **Weekly workload is not program-specific.** Harvard publishes a general rule of at least two hours outside class per class hour, but no certificate-specific minimum and maximum weekly hours.[^7]
- **Course availability can change.** Harvard says multiple options are available in fall, spring, and summer and that “Offerings vary by term”; therefore, named Spring 2027 options should not be treated as a permanent exhaustive curriculum.[^1]
- **Master’s credit is conditional, not automatic for every course.** The certificate can stack into Management or Industrial-Organizational Psychology, but Harvard explicitly warns that “Not every certificate course counts toward a degree.”[^12][^1]
- **The accreditation field is intentionally empty under the requested schema for a non-degree certificate.** Harvard Extension School itself states that it is NECHE-accredited, but no separate programmatic accreditation is published for this certificate.[^7]
- **No primary on-site city exists for the program.** Cambridge is Harvard Extension School’s institutional location, but all four certificate courses are online and no residency is required.[^7][^1]
